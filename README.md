# Светокот

Telegram-бот и Mini App для умных ламп Sber. Работает в Cloudflare Worker, поэтому свет управляется, даже когда Mac выключен.

- Цвет, белый 1500-9000 K, яркость, сцены, ночник, для обеих ламп сразу и по отдельности.
- Циркадный режим по восходу и закату Минска (cron воркера), ручная настройка ставит его на паузу до утра.
- Рассвет под будильник по дням недели, таймер сна с плавным затуханием.
- Темы: авто, светлая, тёмная, Y2K с 3D-лампой и «Котики», где ночник это кот, которого можно погладить.
- Доступ только владельцу и тем, кого он добавил.

Код воркера: `worker/`. Деплой: `cd worker && npx wrangler deploy`, секреты через `wrangler secret put`. Тесты: `node --test worker/test`.

Сделано вместе с Claude Code: идея, постановка задачи, проверка и поиск багов мои, код писал агент.
