# План: Telegram Mini App для ламп Sber

## Цель
Новый Telegram-бот с красивой Mini App в стиле Mini App бота БЖД (/Users/macbook/bilet-bzd) для двух ламп Sber A70 в спальне: цвет, белый, яркость, сцены, «Ночник», циркадный режим по солнцу, рассвет под будильник, таймер засыпания. Без своего сервера: всё живёт в Cloudflare Worker пользователя и работает, даже когда Мак выключен.

## Критерий готовности
- [ ] Бот отвечает владельцу на /start: кнопка Mini App + быстрые кнопки (вкл, выкл, ночник, циркадный); чужим не отвечает.
- [ ] Mini App открывается из бота, показывает реальное состояние ламп (вкл/выкл, цвет или температура, яркость) и меняет его.
- [ ] Цвет, белый 1500–9000 K, яркость, сцены и «Ночник» работают на обеих лампах вместе и на каждой отдельно.
- [ ] Циркадный режим работает из cron воркера по восходу и закату Минска, ручная настройка ставит его на паузу до утреннего перехода; launchd-агент на Маке выключен.
- [ ] Рассвет под будильник срабатывает в заданные дни и время; таймер засыпания плавно гасит свет.
- [ ] Темы Авто / Светлая / Тёмная / Котики / «Под цвет ламп» переключаются и запоминаются.
- [ ] Владелец может добавить и убрать других пользователей.
- [ ] Ни одной сырой ошибки в интерфейсе (как в БЖД: «Сервис временно недоступен» вместо текста исключения).

Аватар и обложка — /Users/macbook/bilet-bzd/brand/ (avatar.svg/png, cover.svg/png). Код бота БЖД не менять.

- API Яндекс Умного дома: https://api.iot.yandex.net/v1.0, заголовок `Authorization: Bearer <токен>`. Токен лежит в /Users/macbook/.config/yandex-iot-token (scopes iot:view, iot:control), в воркер класть секретом `wrangler secret put YANDEX_TOKEN`, не в код и не в git.
  - GET /user/info — устройства, комнаты, capabilities и state.
  - POST /devices/actions — тело `{"devices":[{"id":..., "actions":[...]}]}`. Действия: `devices.capabilities.on_off` instance `on`; `devices.capabilities.range` instance `brightness` (1–100); `devices.capabilities.color_setting` instance `temperature_k` (1500–9000), `hsv` ({h,s,v}), `scene` (candle, ocean, romance, night, dinner, garland, rest).
  - Лампы в Яндексе: обе называются «Лампа», комната «Спальня», id 07bdc6e3-e577-4ae8-8bc4-a87e6a34b62b и ba30f84b-4f56-49dd-b3ac-b3922d71de83. Для понятности в UI переименовать в «Лампа 1» и «Лампа 2» (своими подписями в настройках, не трогая Яндекс).
  - Рабочий пример на Python: /Users/macbook/yandex-lamps/lamps.py (функции act_*, send, circadian_temp).
- CORS: ни API Яндекса, ни шлюз Сбера не отдают Access-Control-Allow-Origin, поэтому Mini App ходит только в свой воркер.
- Прямой шлюз Сбера (sber.py) из Cloudflare недоступен: Cloudflare не доверяет Russian Trusted Root CA. В воркере используем только Яндекс. sber.py остаётся локальным инструментом.
- «Ночник»: Яндекс-сцена `candle`. Яркость сцены хранится в самой лампе (scene_brightness=50 уже записан через `sber.py night`; тест 2026-10-27 показал, что Яндекс-«свеча» после этого даёт ту же темноту). Яркость 1% из Яндекса меняет light_brightness, а не яркость сцены. Если яркость сцены собьётся, владелец один раз запускает `python3 /Users/macbook/yandex-lamps/sber.py night`.
- Красный в цветном режиме не темнее v=100 из 1000 (= 1% в Яндексе); ниже лампа поднимает сама.
- Задержка: команда через Яндекс 300–750 мс (до ответа API).
- Циркадный режим сейчас: launchd-агент com.user.lamps-circadian (/Users/macbook/Library/LaunchAgents/com.user.lamps-circadian.plist, лог /Users/macbook/yandex-lamps/circadian.log): 2700 K ночью, 5500 K днём, переходы 07:00–09:00 и 18:00–20:00, яркость 100%, трогает только включённые лампы, обновляет раз в 5 минут, пропускает изменения меньше 50 K.

## Решения из интервью
- Прослойка → Cloudflare Worker (тот же аккаунт, что у бота БЖД), лампами управляет через API Яндекса.
- Хранилище → D1 (настройки, пользователи, будильники, состояние паузы циркадного), как в БЖД.
- Циркадный → cron воркера раз в минуту; после проверки выключить launchd-агент на Маке (`launchctl unload ~/Library/LaunchAgents/com.user.lamps-circadian.plist`).
- Бот → новый отдельный, токен через BotFather, вебхук на воркер.
- Имя, аватар, обложка → придумать самому, в стиле brand/ БЖД: лампочка + котик. Сделать avatar.svg/png и cover.svg/png в /Users/macbook/yandex-lamps/worker/brand/.
- Темы → Авто / Светлая / Тёмная / Котики (как в БЖД) + «Под цвет ламп» (фон и акценты подкрашены текущим цветом ламп). Выбор запоминать (Telegram CloudStorage или localStorage).
- Главный экран → сверху большая светящаяся лампочка с мягким свечением текущего цвета, тап включает и выключает. Над ней чипсы «Обе / Лампа 1 / Лампа 2». Ниже вкладки: Цвет (круг HSV + яркость) / Белый (ползунок 1500–9000 K с градиентом + яркость) / Сцены (Ночник, сцены Яндекса, свои сохранённые пресеты) / Режимы (циркадный, рассвет, таймер).
- Отклик → команда уходит, когда палец отпущен (не во время ведения). Свечение лампочки на экране меняется сразу.
- Циркадный → по реальным восходу и закату Минска (53.90, 27.56, Europe/Minsk): утренний переход от восхода, вечерний — к закату (длительность перехода и температуры дня и ночи настраиваются, по умолчанию 2700 K / 5500 K, 120 мин). Яркость всегда 100%. Трогает только включённые лампы. На экране — график температуры на сутки с отметкой «сейчас».
- Ручная настройка (цвет, белый, сцена, ночник) → циркадный на паузе до следующего утреннего перехода, потом включается сам. Кнопка «Вернуть циркадный» снимает паузу сразу.
- Рассвет под будильник → время и дни недели; за 20–30 мин (настраивается) лампы плавно разгораются от тёплого тусклого (2700 K, 1%) до дневного (5500 K, 100%) шагами раз в минуту.
- Таймер засыпания → 15 / 30 / 60 мин: плавно уменьшает яркость, в конце «Ночник», затем выключение.
- Чат → /start с кнопкой Mini App (web_app) и inline-кнопки: Вкл, Выкл, Ночник, Циркадный. Кнопка меню бота открывает Mini App.
- Доступ → владелец Telegram id 981748795 (как OWNER_CHAT в БЖД) + список, который владелец ведёт в Mini App (по Telegram id или через пересланное сообщение/контакт). Каждый запрос Mini App проверять по initData (HMAC-SHA256, ключ = HMAC("WebAppData", BOT_TOKEN)), отклонять устаревшие (auth_date старше 24 ч). Вебхук проверять по secret_token.
- Процесс → сделать всё целиком, показать уже работающего бота.

## Допущения
- Часовой пояс Europe/Minsk (UTC+3, без перехода на летнее время).
- Восход и закат считать в воркере по стандартной формуле NOAA, без внешних API.
- cron раз в минуту укладывается в бесплатный тариф Cloudflare; писать в D1 только при изменениях.
- Состояние ламп для UI читать из GET /user/info (кешировать в воркере на ~2 с, чтобы не долбить API).

- Изменения в боте БЖД.
- Синхронизация с музыкой, геозоны, голосовые команды.
